Este proyecto usa el stack definido en el README.md. Componenetes funcionales, sin clases. Usa el sistema de diseño ya presente en el repo si existe; no crees componenetes duplicados si ya existe uno equivalente. No inventes dependencias nuevas sin justificar el plan. El manejo de estado va en hooks o en el store ya definido, nunca mezclando directo el JSX. Toda llamada a la API pasa por la capa de servicios existente, nunca fetch/axios sueltos dentro de un componenete. Nombre de archivos y componentes en PascalCase, hooks con prefijo "use". Antes de tocar estilos globales o el sistema de diseño, justificalo en el plan.
